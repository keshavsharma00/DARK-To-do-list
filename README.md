# DARK-To-do-list
A simple and responsive To-Do List web app built with HTML, CSS and JavaScript.

🔗 **Live Demo:** https://keshavsharma00.github.io/DARK-To-do-list/

## Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed (completed tasks are styled differently)
- Delete tasks
- Tasks are saved in **localStorage**, so they remain after page refresh
- Responsive design for mobile and desktop

## Tech Stack
- HTML5
- CSS3
- JavaScript (DOM Manipulation, localStorage)
